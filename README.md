# Tango Puzzle Game ☀️🌙

A Python-based Tango grid puzzle simulation and solver built using Object-Oriented Programming (OOP). It features real-time error validation, interactive gameplay, and an automated AI solver powered by Depth-First Search (DFS) with Backtracking.

## 🚀 Features
- **Object-Oriented Design:** Clean and modular code structure.
- **Interactive Mode:** Play manually with real-time error highlighting using ANSI codes.
- **AI Solver Mode:** Automatically solves complex puzzle configurations using DFS & Backtracking.

## 🛠️ Tech Stack
- **Language:** Python
- **Concepts:** OOP, Search Algorithms, Backtracking
